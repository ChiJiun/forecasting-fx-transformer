# 各模型適合的資料類型、優缺點與架構解釋

本文件整理本專案用過（含延伸實驗新增）的所有模型族，從**架構的歸納偏誤（inductive bias）**出發，說明每個模型「假設資料長什麼樣」、因此適合哪類資料、在匯率這種資料上為什麼表現如本專案所見。所有實證數字來自 `experiments/results/`（原框架，2 fold × 52 起點 × 11 貨幣）與 `experiments/results_ext/`（延伸實驗）。

> 核心背景：匯率日資料的「可預測結構」極弱——log 報酬近似白噪音（lag-1 自相關 |ρ| < 0.03）、無季節性、無穩定趨勢、波動叢聚（volatility clustering）明顯、橫斷面高度相關（第一主成分解釋 57% 變異）。任何模型的表現都要放在這個背景下理解：**模型的歸納偏誤若與資料不符，額外容量只會變成雜訊擬合**。

## 1. Random Walk 與 RW + drift

**機制**：RW 預測未來所有天都等於最後觀測值；RW+drift 用 context 內的平均日變化線性外推。

**假設**：RW 假設價格是鞅——所有已知資訊已反映在當前價格。這不是「沒有模型」，而是效率市場假說的直接體現，也是 Meese–Rogoff (1983) 以來匯率文獻的標準基準。

**適合**：高流動性金融價格（匯率、股價、大宗商品）。**不適合**：任何有真實趨勢或季節的序列。

**本專案證據**：20 個模型無一顯著優於 RW；RW+drift 顯著更差（MASE 5.555），說明 90 天內的局部趨勢**不會延續**——短期動能在日頻 G10 匯率上不存在，反而外推會放大誤差（h=30 MAE 比 RW 高 21%）。

## 2. Ridge 多輸出回歸

**機制**：把 h=1..30 的累積 log 報酬當 30 個輸出，用最近 20 日報酬（可加理論特徵）做線性回歸，L2 懲罰係數大小。

**為什麼在這裡最好**：
- 線性 + 強正則化 = 容量最低。當真實訊號極弱（R² 可能 < 1%），任何多餘容量都會擬合雜訊；Ridge 的偏誤–變異權衡剛好落在「幾乎等於 RW、但允許一點點修正」。
- 直接多步輸出（direct multi-step）避免遞迴預測的誤差累積。
- 理論特徵（利差、遠期溢價）是**標準化後**進入，係數不會被 α 壓死；但落後報酬是原始尺度（~0.005），在 α=10 下其係數幾乎為零——這解釋了為什麼 `ridge_returns` 與 RW 幾乎一樣（MASE 5.026 vs 5.042），而「訊號」幾乎全來自理論特徵。延伸實驗的 `RidgeStd` 已修正此點（標準化 + 驗證集選 α），結果見 §9。

**適合**：訊噪比極低、特徵少、樣本多、關係近線性的問題。**不適合**：非線性門檻（如央行干預區間）、長記憶。

**缺點**：無法表達互動效應；對特徵尺度敏感（本專案親身示範）；α 的選擇在不同 fold 可能差很多（fold 0 選 100、fold 1 選 0.1），代表訊號不穩定。

## 3. Random Forest 與 MLP

**Random Forest**：bagging 多棵決策樹，每棵樹對特徵做門檻切分，預測為分段常數。
- 假設：目標與特徵的關係可用「若 X > c 則 …」表達，有非線性與互動。
- 適合：表格資料、類別變數多、門檻效應（例如利差 > 3% 時行為改變）。
- 不適合：需要**外推**的回歸（樹不能預測訓練範圍外的值）、平滑連續的關係（分段常數會浪費樣本）。
- 本專案：MASE 5.09–5.12，略差於 RW；加理論特徵後點位也沒改善。樹模型對落後報酬這類近乎純雜訊的特徵會過度切分。

**MLP**：兩三層全連接非線性。
- 假設：任意平滑函數，但沒有序列結構的先驗（輸入順序可以打亂）。
- 適合：中等樣本、特徵間非線性但不需時間歸納偏誤。
- 不適合：小樣本或訊號極弱——容量太大、沒有正則化先驗，容易過擬合。
- 本專案：無特徵版 MASE 5.034（幾乎等於 RW，因為它學到了「什麼都不做」），加特徵後 5.128（顯著更差，p=0.046）——高容量模型拿到有資訊的特徵後反而把它用壞，和 Ridge 恰好相反。

## 4. NLinear 與 DLinear（Zeng et al., AAAI 2023）

兩者都是「一層線性層就能打敗 Transformer」論文的模型，差別在前處理。

**NLinear**：輸入減去最後一個值（instance normalization），過一層線性，加回去。
- 假設：序列經「減最後值」後平穩，且未來是過去的線性函數。
- 等價於用 90 個落後 log 累積報酬做線性回歸——和 Ridge 的差別只在正則化方式（early stopping + weight decay vs L2）與輸入長度。
- 本專案 MASE 5.158（顯著差於 RW，p=0.02）。原因：90 個輸入、30 個輸出 = 2,700 個參數，用梯度法在 23k 樣本上訓練，正則化不如 Ridge 乾淨；它學到了不存在的 lag 結構。

**DLinear**：先用移動平均（kernel 25）把序列拆成趨勢與殘差，各過一層線性再相加。
- 假設：序列 = 平滑趨勢 + 季節/殘差，且兩者可分開線性預測。這在電力負載、交通流量等有強週期的資料上非常有效。
- 匯率沒有季節；移動平均趨勢只是過去 25 天的平均——用它外推等於假設局部趨勢延續，和 RW+drift 的失敗原因一樣。本專案 MASE 5.147（p=0.026 顯著較差）。
- **消融**：不做 instance normalization 的 `dlinear_raw_level` MASE 7.06（p<10⁻¹³）。因為各貨幣尺度差數千倍（KRW ~1300 vs CHF ~0.9），不平穩化的線性層根本無法共用。這是本專案最乾淨的「前處理 > 架構」證據。

**適合**：平穩或差分後平穩、有趨勢/季節的中長序列。**不適合**：無結構的隨機漫步。

## 5. PatchTST（Nie et al., ICLR 2023）

**機制**：
1. 把每條序列切成長度 P 的 patch（本專案 90 天切 9 個 10 天 patch），每個 patch 線性嵌入成一個 token。
2. Token 之間做自注意力（Transformer encoder）。
3. **Channel-independent**：每條貨幣各自過同一個網路，不看其他貨幣。
4. 最後 flatten 所有 token 過線性層輸出 30 步。

**為什麼 patch**：把點級別的 token 變成片段級別，(a) 注意力長度從 L 降到 L/P，(b) 每個 token 含局部語意（例如「一段上升」），(c) 大幅減少參數與過擬合。

**為什麼 channel-independent 反而好**：各貨幣共用權重 = 樣本數 ×11，而且不會學到貨幣間偽相關；原論文發現這在大多數 benchmark 上優於 channel-mixing。

**適合**：context 長（≥ 數百步）、有重複的局部形狀（例如日內週期、週週期）、多變量但各變量可視為獨立的資料。

**不適合**：短 context、無重複形狀的白噪音。90 天匯率只有 9 個 patch，注意力沒什麼可以「注意」的；本專案 MASE 5.055–5.106，與 RW 無顯著差異（調參後幾乎等於 RW），seed 間變異可觀（4.14–4.22）。加理論特徵版（5.359）顯著更差——把 4 個特徵當額外 channel 混進 patch，Transformer 會過度利用它們。

**缺點**：訓練成本高（CPU 上一次 ~100–180 秒，是 NLinear 的 50 倍）、對 seed 敏感、需要調 patch 長度/層數。

## 6. HF TimeSeriesTransformer / Informer / Autoformer（早期實驗使用）

這三個都是 Hugging Face 實作的**encoder–decoder 機率預測模型**（Informer、Autoformer 繼承同一個 TimeSeriesTransformer 骨架），輸入包含落後值（lags_sequence）、時間特徵、靜態類別（貨幣 ID）、動態實值 covariates，輸出 Student-t 分佈參數。

**共同假設**：多序列之間有可共享的結構（用 ID 嵌入區分）、未來的 covariates 已知（日曆特徵、促銷計畫等）、分佈輸出有價值。這套設計源自零售/需求預測（如 M5 競賽），covariates 與日曆效應才是它們的主戰場。

**在匯率上的問題**：
- 匯率沒有日曆效應（day-of-week/month 特徵是雜訊）。
- 原實驗把未來 FFX / 利率當 dynamic covariates 餵進去——這在需求預測是合法的（未來促銷是計畫好的），在匯率是洩漏（未來遠期匯率 ≈ 未來即期匯率）。修正後 MASE 6.19（p=0.024 顯著差於 RW），seed 間變異很大（4.62 vs 5.27）。
- 4 層 encoder + 4 層 decoder、d_model 32、lags 到 37 天：參數相對樣本過多，而 decoder 的自回歸結構會累積誤差。

**Informer 的獨特機制**：ProbSparse 注意力（只算 top-u 個「活躍」query）+ 自注意力蒸餾（每層後把序列長度減半）。目的是把注意力複雜度從 O(L²) 降到 O(L log L)，讓 context 可以到數千步。**當 context 只有 90 步時這些機制沒有意義**——稀疏化反而丟掉資訊。適合：超長輸入的電力/感測器資料。

**Autoformer 的獨特機制**：(a) 序列分解區塊（移動平均分趨勢/季節，在網路內反覆做），(b) 自相關機制取代點對點注意力——用 FFT 算序列的自相關，找出 top-k 個週期 τ，把序列位移 τ 後聚合。**整個設計以「序列有週期性」為前提**。匯率日報酬的自相關函數在所有 lag 都 ≈ 0，自相關機制會挑出純雜訊的 τ。適合：強季節性的電力、天氣、交通資料。

**總結**：這三者是為「長、有週期、有已知 covariates」的序列設計的；匯率三個條件都不滿足。

## 7. Chronos-Bolt（基礎模型，零樣本）

**機制**：把數值序列經縮放 + 分箱 token 化，用 T5 風格 encoder–decoder 在大量公開時序資料（+ 合成資料）上預訓練；Bolt 版直接輸出多步分位數。

**假設**：不同領域的時序共享「通用模式」（趨勢、季節、均值回復、水準變化），這些模式可以從其他資料學會後遷移。

**適合**：沒有訓練資料或資料極少的新序列、有常見模式的業務指標、需要快速得到合理區間預測。

**不適合**：效率市場價格。預訓練語料中的「模式」在匯率上是不存在的結構，模型仍會「看到」它們並做出偏離 RW 的預測。本專案 MASE 5.589（比 RW 差 11%，p=0.052），h=1 誤差比 RW 高 17%——它在最短視野就開始「畫圖」。另外其語料可能含金融序列，零樣本結果不算嚴格 out-of-sample。

**優點**：完全不用訓練、一行程式；**缺點**：對無結構資料會自信地畫出不存在的結構，無法加入領域特徵（利差等）。

## 8. 多尺度輸入模型（延伸實驗 2 新增）

**機制**：從日資料用「每 5 天 / 每 21 天取樣」造出週、月兩條 context（各 52、24 點），三個尺度分別嵌入（Ridge：各尺度落後報酬串接；NLinear：串接後一層線性；PatchTST：各尺度各自 patch + 尺度嵌入，共用 encoder）。另有 480 天日頻版做「只是看更長」的對照。

**假設**：不同頻率各有結構（例如日內均值回復 + 月度動能），且長期資訊用粗取樣表示比用細取樣更不容易過擬合。

**適合**：有多重週期的資料（電力：日 + 週 + 年；零售：週 + 年）。

**在匯率上**（`extension_report.md` §2）：週/月尺度不帶來任何點位改善。Ridge：d20 為 0.999，加任何尺度 1.003–1.016；NLinear：單一月尺度（24 維）反而最好（1.013），串接全差；PatchTST：加週尺度顯著變差（1.062，p=0.011）、加月尺度 1.106（p<0.001）。長日頻對照（480 天）顯示「粗取樣比細取樣的長歷史便宜」，但兩者都只是加雜訊維度——匯率在週頻（|ρ| ≤ 0.08）、月頻（|ρ| ≤ 0.19，約 240 個觀測、符號不一致）的報酬自相關與日頻一樣沒有可用結構。

## 9. 跨貨幣模型（延伸實驗 3 新增）

**iTransformer（Liu et al., ICLR 2024）**：把 PatchTST 的 token 軸反轉——每條貨幣整段 90 天 context 嵌入成**一個** token，注意力在 11 條貨幣之間進行。假設：變量間的相關/領先落後是主要可學結構。

**跨貨幣 PatchTST**：token = (貨幣, patch)，11 × 9 = 99 個 token 一起做注意力。

**多變量線性**：11 × 90 → 11 × 30 的單層線性（channel-mixing 的最簡形式）。

**Ridge + 跨貨幣特徵**：每個目標貨幣一個 Ridge，自身 20 日報酬 + (美元因子 / 前 3 主成分 / 其餘 10 貨幣) 最近 k 日報酬。

**共同代價**：樣本數從「起點 × 貨幣」（~23k）掉到「起點」（~2.1k），神經網路版本很容易過擬合。

**在匯率上**（`extension_report.md` §3）：
- Ridge + 其餘 10 貨幣最近 1 日報酬：KRW+TWD 的路徑 MASE 改善 1.8%（DM p=0.006）、h=1 改善 3.5%（p=0.002），兩 fold 一致；**其餘 9 貨幣比值 1.000**，完全沒有效果。
- 所有 channel-mixing 神經網路（iTransformer 1.028、跨貨幣 PatchTST 1.035、多變量線性 1.180）都差於 channel-independent 對照（NLinear 1.023、PatchTST 1.017），h=1 差最多（+10% / +20% / +47%）：樣本數從 23k 掉到 2.1k、輸入維度從 90 漲到 990，過擬合。
- 效果集中在 KRW/TWD 的原因：這兩個貨幣的 WM/R 定盤價取自亞洲時段收盤，G10 當日倫敦時段的走勢要到次日才反映到 KRW/TWD，形成 lag-1 相關 ~0.2；G10 之間沒有 lead-lag。這是「資料時間戳不同步」造成的可預測性，不是經濟上的領先落後，實務上也不可交易（定盤價已過時）。
- 教訓：跨貨幣資訊存在但**極稀疏**（兩個目標 × 一天的 lag），10 個 Ridge 係數就裝得下；注意力機制要從 2.1k 筆樣本學會這種稀疏結構，代價是在其他 9 條貨幣上全面過擬合。iTransformer 的設計前提（變量間有豐富、穩定的相關可學）在這裡不成立。

## 10. 設計原則總結（從本專案得到的教訓）

1. **先問資料有什麼結構，再選模型**。匯率日資料：無趨勢（RW+drift、DLinear 失敗）、無季節（Autoformer 無用武之地）、短 context 就夠（Informer 稀疏化無意義）、無 covariates 可用（HF Transformer 失去優勢）、橫斷面相關強但同步（跨貨幣對 h>1 無用）。
2. **容量要配訊噪比**。訊號極弱時，Ridge > MLP > Transformer；同一組理論特徵給 Ridge 幾乎無害、給 MLP/PatchTST 反而點位變差。
3. **前處理比架構重要**。instance normalization 的消融（p<10⁻¹³）遠大於任何架構間差異（全部 <1%）。
4. **對照組要設對**。多尺度 vs 長日頻、跨貨幣 vs 自身、全域 vs 區域 vs 留一——沒有這些對照，很容易把「資料變多」或「正則化變了」誤認為架構貢獻。
5. **基礎模型不是免費午餐**。預訓練學到的「通用模式」在效率市場上是幻覺。
