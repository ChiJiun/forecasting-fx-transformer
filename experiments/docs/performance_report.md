# 詳盡表現報告

本文件完整記錄所有實驗的表現數據。評估設定：2 個年度測試區間（2023-03-03~2024-02-23、2022-03-04~2023-02-24）、每區間 52 個預測起點（stride 5）× 11 條貨幣序列，預測 30 天路徑；神經模型 3 seeds 平均。

**注意：本結果產生時理論特徵未延後（feat_lag=0）**。AUD/CAD/DKK/JPY/NOK/CHF/GBP 的遠期匯率取價晚於即期定盤，`fwd_premium` 含次日即期報酬資訊，帶 `_feat` 的結果不可採信（見 docs/extension_report.md §0）。目前 `load_panel` 預設 feat_lag=1，重跑實驗即可得到修正後的結果。

## 9. 表現總結

1. **點位**：沒有任何模型在 5% 水準顯著優於 Random Walk。MASE 最低的是 Ridge + 理論特徵（MASE 比 0.993，DM p=0.336）。在 5% 水準顯著**差於** RW 的模型：MLP + 理論特徵（MASE 比 1.017，p=0.037）、DLinear（MASE 比 1.021，p=0.035）、NLinear（MASE 比 1.023，p=0.025）、Chronos-Bolt (零樣本)（MASE 比 1.109，p=0.032）、HF Transformer (原報告模型)（MASE 比 1.228，p=0.006）、NLinear + 理論特徵（MASE 比 1.255，p<0.001）、DLinear (raw level 消融)（MASE 比 1.401，p<0.001）；0.05–0.10 之間差於 RW 的模型：PatchTST + 理論特徵（MASE 比 1.063，p=0.091）、RW + drift（MASE 比 1.102，p=0.061）。（DM 以 MASE 為損失、雙尾檢定。）
2. 本節數字由第 1 節總表動態產生；理論特徵的時間戳處理見文件開頭說明。
