## 9. 表現總結

1. **點位**：20 個變體無一顯著優於 Random Walk；最佳差距僅 0.7%（p=0.21）。專項挑戰（shrinkage/遠期偏誤/美元因子、780 起點）亦然。
2. **高容量模型更差**：HF Transformer、NLinear+特徵、raw level 消融顯著劣於 RW（p<0.05），Chronos-Bolt 邊緣（p=0.052）。
3. **穩健性**：上述結論跨兩個年度區間、20 組超參數、多 seed 皆成立。
